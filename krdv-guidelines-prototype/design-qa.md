# ERDCBB — технический аудит 12 октября 2026

Исходный коммит: `9bdf906b6003e315aca718132403bcfa6b5e6f5d` от 24.08.2026. Этот документ описывает отдельную рабочую ветку и **не означает**, что изменения уже развернуты на GitHub Pages.

## Исправленные проблемы

- Монолитная структура: данные, ресурсы и интерфейс разделены на функциональные модули.
- Монолитный CSS: разделён по областям без изменения порядка каскада.
- Устаревшие публичные hash-маршруты: сохранена совместимость.
- Мобильное меню: Escape, inert для скрытого меню, цикл фокуса, возврат фокуса и связь aria-controls.
- Копирование HEX: ошибки доступа к буферу обмена больше не маскируются под успех.
- Интерактивный просмотр шрифта: ввод и изменение размера больше не перемонтируют анимированный блок.
- Автопроигрывание видео вне области видимости: добавлены постеры, управление видимостью, фоновыми вкладками и reduced-motion.
- Тяжёлый WebGL: шейдер загружается отложенно, с CSS-подложкой.
- GSAP-сцены вне viewport приостанавливаются.
- Основной контент больше не скрыт при недоступном IntersectionObserver.
- Ошибка типографа для чисел с кириллическими единицами измерения.
- Добавлены проверки файлов, страниц, маршрутов и браузерные тесты desktop/mobile.

## Проверки

- `npm run build` — успешная сборка.
- `npm test` — 10 тестов целостности и логики проходят.
- `npm run test:e2e` — обязательно для финального подтверждения визуального и функционального поведения.
- В workflow деплоя добавлен контроль тестов перед публикацией.
- Проверка точного совпадения с утверждённым исходным брендбуком требует финального PDF, который отсутствует в репозитории.

## Открытые вопросы с внешними зависимостями

1. Право на публичное размещение и скачивание TT Norms Pro / TT Tsars и шрифтового ZIP-архива. Пока правовой статус не подтвержден, нельзя утверждать соответствие лицензии.
2. Ссылки Яндекс Диска (некоторые содержат `/client/aa/`) требуют проверки в обычном пользовательском браузере: автоматическая проверка упирается в CAPTCHA.
3. Историческая спецификация обещала отдельный Logo Lab и фотогалерею с вкладками, которых нет в текущей продуктовой версии. Реализацию следует подтвердить с владельцем брендбука, чтобы не добавлять неподтвержденное поведение.
4. Финальная сверка содержимого с PDF и утвержденными дизайнами — отдельный этап при получении исходника.

Неподтверждённые внешние зависимости нельзя автоматически объявлять «исправленными».
