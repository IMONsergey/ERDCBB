## Проверка перед публикацией

- `GITHUB_PAGES=true npm run check`: статическая сборка, ESLint и unit/integrity-тесты.
- `npm run test:e2e -- --workers=2 --reporter=line`: Chromium, мобильный Chromium, Firefox, десктопный и мобильный WebKit.
- Новые тесты фиксируют 320–1440 px, переносы, шрифтовой размер, глубокие ссылки, clipboard race/fallback, доступ к SVG и print.
- PR остаётся неслитым до успешного итогового запуска GitHub Actions. GitHub Pages запускает ту же защиту перед выкладкой.

## Не изменялось / ограничения

- Официальные файлы логотипов, фирменная палитра, названия разделов, содержательная редакция и макеты.
- Право публичного использования TT Norms Pro и TT Tsars нуждается в подтверждённой лицензии.
- Недоступные архивы Яндекс Диска по-прежнему требуют публичных ссылок от владельца.
- Без утверждённого оригинального PDF нельзя заверить текстовую идентичность каждой инструкции.
- Системное E2E-покрытие не эквивалентно измеренному росту Core Web Vitals или визуальной приёмке на всех реальных устройствах.
