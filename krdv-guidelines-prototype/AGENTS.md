# ERDCBB — правила сопровождения

- Сохранять идентичность и композицию фирменного стиля КРДВ. Внутренний рефакторинг не является разрешением на редизайн.
- Все данные страниц — в `src/data/pages.js`, словари ассетов — в `src/data/resources.js`. Не складывать сотни строк контента обратно в компоненты.
- Не оставлять сломанных локальных загрузок: все пути должны существовать в `public/`, проверять `npm run check`.
- Сохранять keyboard focus/ESC/inert в мобильной навигации и проверять reduced-motion.
- Видео должны иметь статичные постеры и не играть за пределами viewport. Шейдер загружать отдельно.
- Оставить `worker/`, `.openai/hosting.json` и `scripts/prepare-sites-build.mjs`: они используются сборкой Sites.
- Не менять публичные шрифтовые лицензии и не удалять утвержденные исходники без правообладателя.
- Запускать `npm run check` и `npm run test:e2e` перед pull request/merge.
- Обновлять `brandbook-map.md` при переименовании разделов или маршрутов.
