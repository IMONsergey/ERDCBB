# ERDCBB

Интерактивная веб-версия брендбука АО «КРДВ»: позиционирование, логотип,
палитра, типографика, графика, корпоративные материалы, рекламные носители,
мерч, фотостиль и приложение.

## Локальный запуск

```bash
cd krdv-guidelines-prototype
npm ci
npm run dev
```

## Проверка

```bash
cd krdv-guidelines-prototype
npm run build
npm run test:sites
```

## GitHub Pages

Публичная страница собирается GitHub Actions из `krdv-guidelines-prototype` и публикуется через GitHub Pages.
