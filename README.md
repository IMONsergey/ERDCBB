# ERDCBB

Внутренний прототип страницы брендбука АО «КРДВ» по разделу «Фотостиль».

## Локальный запуск

```bash
cd krdv-guidelines-prototype
npm ci
npm run dev
```

## Проверка

```bash
cd krdv-guidelines-prototype
npm run build
npm run test:sites
```

## GitHub Pages

Публичная страница собирается GitHub Actions из `krdv-guidelines-prototype` и публикуется через GitHub Pages.
